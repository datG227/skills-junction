Skills Junction — WebView2

Cách mở
- Chạy SkillsJunction.WebView2.exe trên Windows 10/11.
- Máy cần có Microsoft Edge WebView2 Runtime và .NET 10 Desktop Runtime.
- Thư mục ứng dụng khoảng 2 MB; WebView2 dùng runtime Edge đã cài sẵn.

Cách dùng
- Chọn Tạo Junction, nhập tên, rồi chọn thư mục Skills nguồn và đích bằng nút Duyệt.
- Bấm Tạo Junction trong biểu mẫu để lưu cặp và tạo Junction ngay.
- Công tắc trên thẻ dùng để gỡ/tạo lại các Junction thuộc cặp đó.
- Skills xem danh sách thư mục con từ nguồn; Sửa và Xóa thao tác theo từng cặp.

Cấu hình lưu tại %LOCALAPPDATA%\SkillsJunction\pairs.json.
Nếu phần xử lý nền dừng, thông báo sẽ hiện trên cửa sổ; nhật ký lưu tại %LOCALAPPDATA%\SkillsJunction\WebView2.log.
